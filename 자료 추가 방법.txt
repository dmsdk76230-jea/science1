📌 [중1 과학 대시보드] 학습지  시뮬레이션  외부링크 추가 매뉴얼
==============================================================

[0. 기본 준비]
- 새로 만든 html 파일이나 pdf 파일은 대시보드(index.html)와 
  '같은 폴더' 안에 넣어두어야 합니다.


[1. 편집 방법]
1) index.html 파일을 우클릭 - [연결 프로그램] - [메모장] (또는 VS Code)
2) 키보드 Ctrl + F 를 눌러 추가하려는 단원 찾기 (예 3단원, 4단원, 5단원, 6단원)
3) 해당 단원의 괄호 [ ] 안에 아래 양식을 복사해서 붙여넣기
4) 저장 Ctrl + S 누르고, 브라우저에서 F5(새로고침)


--------------------------------------------------------------
📋 [복사해서 쓸 양식 모음]
--------------------------------------------------------------

■ 1. 시뮬레이션 (HTML) 추가할 때
- simulations [ ... ] 안에 아래 내용을 복사해서 넣으세요.

          {
            title 시뮬레이션 제목,
            file 파일명.html,
            desc 학생들을 위한 한 줄 설명
          },


■ 2. 학습지 (PDF) 추가할 때
- worksheets [ ... ] 안에 아래 한 줄을 복사해서 넣으세요.

          { title 학습지 제목, file 파일명.pdf },


■ 3. 외부 링크 (유튜브 영상, 웹사이트 등) 추가할 때
- links [ ... ] 안에 아래 한 줄을 복사해서 넣으세요.

          { title 링크 제목, url https인터넷주소 },


--------------------------------------------------------------
⚠️ [자주 하는 실수 & 주의사항 3가지]
--------------------------------------------------------------
1. 끝에 쉼표(,) 잊지 마세요!
   - 여러 개를 나열할 때는 항목 사이에 반드시 쉼표(,)가 있어야 합니다.

2. 확장자(.html, .pdf)까지 정확하게 적어주세요!
   - 윈도우에서 확장자가 숨겨져 있더라도 코드에는 꼭 .html, .pdf를 붙여야 열립니다.

3. 오타 주의!
   - 실제 파일 이름과 코드에 적은 파일 이름이 띄어쓰기 하나까지 똑같아야 합니다.
